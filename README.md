## Proyectos

### 1. Car Detail / Imperio Detail
Proyecto de identidad y presencia digital para un emprendimiento de detailing automotriz. Se trabajó una landing page con identidad visual, hero banner, video pitch y estructura orientada a presentar servicios.

### 2. Sistema de Gestión de Stock
Proyecto académico orientado a backend y bases de datos. Se documenta la estructura de una solución para registrar productos y controlar stock. La carpeta `backend-stock` contiene la documentación y el modelo SQL de ejemplo.

## Publicación con GitHub Pages

1. Crear un repositorio público en GitHub.
2. Subir todos los archivos de este proyecto.
3. Ir a **Settings > Pages**.
4. En **Build and deployment**, seleccionar **Deploy from a branch**.
5. Seleccionar la rama `main` y la carpeta `/ (root)`.
6. Guardar y esperar a que GitHub publique el sitio.
7. Copiar la URL de GitHub Pages y colocarla en este README y en la entrega de Classroom.
