# GUÍA DE ENTREGA - FAT TP08

## PASO 1 — Personalizar
Abrí `index.html` y reemplazá:
- [TU NOMBRE]
- TU_EMAIL
- TU_USUARIO
- cualquier dato que no corresponda a vos.

## PASO 2 — Revisar proyectos
El TP exige al menos 2 proyectos. Este portfolio ya contiene:
1. Car Detail / Imperio Detail.
2. Sistema de Gestión de Stock.

Si tenés un proyecto real de backend/base de datos hecho en la escuela, reemplazá la documentación del ejemplo por tu proyecto real y agregá sus capturas.

## PASO 3 — Crear GitHub
1. Entrá a https://github.com/
2. Iniciá sesión.
3. Tocá `New repository`.
4. Poné un nombre, por ejemplo: `portfolio-fat-2026`.
5. Seleccioná `Public`.
6. Creá el repositorio.

## PASO 4 — Subir archivos
Subí al repositorio:
- index.html
- style.css
- script.js
- README.md
- carpeta backend-stock

## PASO 5 — Activar GitHub Pages
Dentro del repositorio:
Settings → Pages → Deploy from a branch → main → / (root) → Save.

## PASO 6 — Esperar la publicación
GitHub generará una dirección similar a:
https://TU_USUARIO.github.io/portfolio-fat-2026/

Abrila desde el celular y comprobá:
- que carga;
- que el menú funciona;
- que se adapta al celular;
- que las secciones aparecen;
- que no hay enlaces rotos.

## PASO 7 — Completar README
Pegá las URLs reales del repositorio y del sitio publicado.

## PASO 8 — Entregar en Classroom
La consigna indica que la entrega debe contener dos enlaces:
1. Repositorio público de GitHub.
2. Sitio web en vivo de GitHub Pages.

Podés poner ambos en un comentario privado de Classroom o en un PDF.
